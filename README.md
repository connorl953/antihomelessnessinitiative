# Anti-Homelessness Initiative

The website for the Anti-Homelessness Initiative, a student-run nonprofit. Built and
deployed September 2022; it ran at **antihomelessnessinitiative.org** via GitHub Pages.

## What this is

A single-page marketing site covering the organization's core values, its plan, its
supporters, and its social links. I built and shipped it end to end: page structure and
sectioning, content, navigation, logo and favicon work, the GitHub Pages deployment, and the
custom domain setup.

The project was supported by [Building U](https://building-u.com), which I was contributing
to at the time.

## Stack

Static HTML, CSS, and JavaScript, on Bootstrap. No framework, no build step — it deploys
straight from the repository.

**Styling is the [Start Bootstrap "Agency"](https://startbootstrap.com/theme/agency) theme**
(MIT licensed), vendored as `css/styles.css`. I customized it rather than writing it; the
hand-written work here is `index.html` and the assets.
